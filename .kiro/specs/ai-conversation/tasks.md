# Implementation Plan

## Task 1: プロジェクト初期セットアップ

- [ ] 1.1 React + TypeScript プロジェクトの初期化
  - Vite または Create React App で React 19 + TypeScript プロジェクトを作成
  - TypeScript strict mode を有効化
  - TailwindCSS を導入してスタイリング基盤を構築
  - ESLint + Prettier の設定
  - 基本的なフォルダ構成（components, services, types）を作成
  - _Requirements: 全体基盤_

- [ ] 1.2 (P) 共通型定義の作成
  - メッセージ、会話セッション、フィードバックのドメインモデル型を定義
  - ユーザーレベル（beginner/intermediate/advanced）の型を定義
  - セッションサマリーの型を定義
  - _Requirements: 1.3, 3.2, 7.3_

## Task 2: ストレージサービスの実装

- [ ] 2.1 (P) LocalStorage を使った会話履歴保存機能
  - セッションの保存・取得・削除機能を実装
  - セッション一覧の取得機能を実装
  - 容量制限（5MB）を超えた場合の古いセッション自動削除
  - エラーハンドリング（LocalStorage 無効時のフォールバック）
  - _Requirements: 6.1, 6.2, 6.3, 6.4_

## Task 3: 会話サービスの実装

- [ ] 3.1 セッション管理機能の実装
  - 新規セッションの作成とID生成（UUID v4）
  - ユーザーレベル設定の読み込みと適用
  - セッション終了時のサマリー計算（メッセージ数、平均応答時間、瞬発力達成回数）
  - ストレージサービスとの連携（自動保存）
  - _Requirements: 1.1, 1.3, 7.1, 7.2, 7.3_

- [ ] 3.2 OpenAI API との通信とストリーミング応答処理
  - Chat Completions API へのリクエスト送信
  - ストリーミング（SSE）による応答のリアルタイム受信
  - 会話履歴を含めた文脈保持リクエストの構築
  - ユーザーレベルに応じたシステムプロンプトの調整
  - あたたかみのある対話スタイルを促すプロンプト設計
  - _Requirements: 2.2, 3.1, 3.2, 3.3, 3.4_

- [ ] 3.3 エラーハンドリングとリトライ機能
  - API エラー（401, 429, 500）に対する適切なエラーメッセージ
  - リトライロジック（最大3回）の実装
  - ネットワークエラー時のフォールバック
  - 再送信オプションの提供
  - _Requirements: 2.4_

## Task 4: フィードバックサービスの実装

- [ ] 4.1 (P) 文法解析とフィードバック生成機能
  - ユーザーメッセージの文法解析リクエスト送信
  - 文法エラーの検出と正しい表現の提案
  - 正しい表現の場合の Congratulations 評価生成
  - より自然な表現の提案機能
  - あたたかみのあるトーンでのフィードバック文生成
  - 高速レスポンスのための最適化
  - _Requirements: 5.2, 5.3, 5.4, 5.5, 5.6_

## Task 5: UI コンポーネントの実装

- [ ] 5.1 メッセージ表示コンポーネントの作成
  - メッセージ一覧を表示するリストコンポーネント
  - ユーザー/AI メッセージを区別する吹き出しスタイル
  - 新しいメッセージ追加時の自動スクロール
  - ストリーミング中のリアルタイム文字表示
  - _Requirements: 2.1_

- [ ] 5.2 メッセージ入力と送信機能
  - テキスト入力フィールドと送信ボタン
  - 空メッセージ送信の防止（バリデーション）
  - 送信中の入力無効化とローディング表示
  - Enter キーでの送信対応
  - _Requirements: 2.1, 2.3_

- [ ] 5.3 (P) 解説ボタンとフィードバックダイアログ
  - ユーザーメッセージ吹き出し下部に解説ボタンを配置
  - モーダルダイアログで文法フィードバックを表示
  - ローディング中の表示
  - エラー/成功（Congratulations）の視覚的区別
  - ダイアログの開閉制御
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5, 5.6_

- [ ] 5.4 (P) 瞬発力タイマーコンポーネント
  - AI メッセージ表示後にタイマーを開始
  - 経過時間をリアルタイムで視覚表示（requestAnimationFrame 使用）
  - ユーザー送信時にタイマー停止と時間記録
  - 1秒以内達成時のポジティブフィードバック表示
  - _Requirements: 4.1, 4.2, 4.3, 4.4_

## Task 6: 会話画面の統合

- [ ] 6.1 会話コンテナの状態管理
  - セッション状態、ローディング状態、エラー状態の管理
  - ストリーミングコンテンツの状態管理
  - タイマー状態との連携
  - 送信中の追加送信ブロック
  - _Requirements: 1.1, 2.1, 2.2, 2.3, 4.1_

- [ ] 6.2 会話開始フロー
  - 会話開始ボタンのクリックでセッション作成
  - ユーザーレベル設定の読み込み
  - AI からの最初の挨拶メッセージ表示
  - 挨拶後のタイマー開始
  - _Requirements: 1.1, 1.2, 1.3_

- [ ] 6.3 会話終了フローとサマリー表示
  - 会話終了ボタンの配置とクリック処理
  - セッション終了時の状態更新
  - 会話統計（メッセージ数、平均応答時間）のサマリー表示
  - セッションの自動保存
  - _Requirements: 7.1, 7.2, 7.3, 6.1_

## Task 7: 会話履歴画面の実装

- [ ] 7.1 (P) 履歴一覧画面
  - 保存された会話セッション一覧の表示
  - セッション情報（日時、メッセージ数）の表示
  - セッション選択時の詳細表示への遷移
  - _Requirements: 6.2_

- [ ] 7.2 (P) 履歴詳細表示
  - 選択したセッションの全メッセージ表示
  - 読み取り専用モード（送信不可）
  - 会話画面への戻る機能
  - _Requirements: 6.3_

- [ ] 7.3 履歴削除機能
  - 削除ボタンの配置
  - 削除確認ダイアログ
  - 削除実行と一覧の更新
  - _Requirements: 6.4_

## Task 8: テストの実装

- [ ] 8.1 サービス層のユニットテスト
  - ConversationService: セッション作成、メッセージ追加、終了処理
  - FeedbackService: 文法解析結果のパース
  - StorageService: LocalStorage 操作のテスト
  - モック API レスポンスを使ったテスト
  - _Requirements: 1.1, 2.1, 3.1, 5.2, 6.1_

- [ ] 8.2 UI コンポーネントのテスト
  - ResponseTimer: タイマー精度、1秒判定のテスト
  - MessageBubble: 表示とスタイルのテスト
  - FeedbackDialog: 開閉と表示内容のテスト
  - _Requirements: 4.1, 4.2, 4.3, 5.1_

- [ ]* 8.3 統合テスト
  - 会話開始から終了までのフロー
  - メッセージ送受信とストリーミング表示
  - フィードバックダイアログの動作
  - 会話履歴の保存・閲覧・削除
  - _Requirements: 1.1, 1.2, 2.1, 2.2, 5.1, 6.2, 6.3, 6.4, 7.1, 7.2_
